# Offline sample data

`prompt_robustness.jsonl` contains twenty small records with `input`,
`expected`, `context`, and `split` fields. It is intentionally tiny and
license-free so the demo can run in a clean, disconnected environment. Add
your own JSON/JSONL/CSV/TXT files through the Dataset Viewer or CLI; the loader
stores a SHA-256 hash in the reproducibility manifest.
